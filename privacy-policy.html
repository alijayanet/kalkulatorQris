Kebijakan Privasi

Aplikasi Kalkulator QRIS Dinamis

Terakhir diperbarui: 1 September 2026

Kebijakan Privasi ini menjelaskan bagaimana aplikasi Kalkulator QRIS Dinamis ("Aplikasi", "Kami") menangani informasi pengguna. Kami sangat menghargai privasi Anda dan berkomitmen untuk melindungi data pribadi Anda.

1. Informasi yang Dikumpulkan

Aplikasi ini dirancang untuk memproses data secara lokal di perangkat Anda. Kami tidak mengumpulkan, mengirim, atau menyimpan data pribadi Anda ke server eksternal manapun.

Data yang Diproses Secara Lokal:

  • Data Profil Merchant: Nama toko, kota, kode pos, NMID, dan MPAN yang Anda masukkan disimpan secara terenkripsi di perangkat Anda menggunakan Android EncryptedSharedPreferences.
  • Riwayat Transaksi: Data transaksi QRIS (nomor invoice, nominal, waktu, status) disimpan secara lokal menggunakan database Room (SQLite) di perangkat Anda.
  • Data QRIS Statis: Payload QRIS dasar yang Anda upload atau masukkan disimpan terenkripsi di perangkat.
  • Pengaturan Printer: Nama dan alamat MAC printer Bluetooth yang dipilih disimpan terenkripsi secara lokal.

2. Izin Aplikasi (Permissions)

Aplikasi ini memerlukan izin-izin berikut untuk berfungsi dengan baik:

🔵 Bluetooth (BLUETOOTH, BLUETOOTH_ADMIN, BLUETOOTH_CONNECT, BLUETOOTH_SCAN)

Digunakan hanya untuk mendeteksi dan terhubung ke printer thermal Bluetooth yang telah dipasangkan (paired) dengan perangkat Anda, guna mencetak struk transaksi. Tidak digunakan untuk pelacakan lokasi atau pengumpulan data.

🔵 Penyimpanan (WRITE_EXTERNAL_STORAGE, READ_EXTERNAL_STORAGE)

Digunakan hanya untuk menyimpan gambar kode QRIS dan struk transaksi ke Galeri perangkat Anda ketika Anda menekan tombol "Simpan ke Galeri". Izin ini hanya diperlukan pada Android 9 (API 28) ke bawah.

🔵 Notifikasi (POST_NOTIFICATIONS)

Digunakan untuk menampilkan notifikasi lokal saat kode QRIS berhasil di-generate dan saat pembayaran berhasil diterima. Notifikasi ini sepenuhnya lokal dan tidak melibatkan server eksternal.

🔵 Internet (INTERNET)

Digunakan untuk layanan Firebase App Check sebagai lapisan keamanan tambahan. Tidak ada data pribadi pengguna yang dikirim melalui koneksi internet.

3. Keamanan Data

Kami menerapkan langkah-langkah keamanan untuk melindungi data Anda:

  • Data sensitif merchant (NMID, MPAN, nama toko) disimpan menggunakan Android EncryptedSharedPreferences dengan enkripsi AES-256.
  • Semua data transaksi tersimpan di database lokal (Room/SQLite) yang hanya bisa diakses oleh aplikasi ini.
  • Tidak ada data yang dikirim ke server pihak ketiga.
  • Koneksi Bluetooth ke printer menggunakan protokol RFCOMM standar.

4. Berbagi Data

Aplikasi ini tidak membagikan data pribadi Anda kepada pihak ketiga manapun. Fitur "Bagikan" hanya membagikan gambar kode QRIS/struk yang Anda pilih secara eksplisit melalui mekanisme Android Share Sheet ke aplikasi pilihan Anda (WhatsApp, Email, dll).

5. Penyimpanan dan Penghapusan Data

  • Semua data tersimpan hanya di perangkat lokal Anda.
  • Anda dapat menghapus seluruh riwayat transaksi kapan saja melalui menu Riwayat → Hapus Semua.
  • Anda dapat mereset data profil merchant melalui menu Pengaturan.
  • Menghapus (uninstall) aplikasi akan menghapus semua data secara permanen dari perangkat Anda.

6. Layanan Pihak Ketiga

Aplikasi ini menggunakan layanan pihak ketiga berikut:

  • Firebase App Check: Digunakan untuk verifikasi integritas aplikasi. Tidak mengumpulkan data pribadi pengguna. Kebijakan Privasi Firebase
  • ZXing: Library open-source untuk generate dan membaca kode QR. Diproses sepenuhnya secara lokal tanpa koneksi jaringan.

7. Privasi Anak-Anak

Aplikasi ini tidak ditujukan untuk anak-anak di bawah usia 13 tahun. Kami tidak secara sengaja mengumpulkan informasi pribadi dari anak-anak. Jika Anda adalah orang tua atau wali dan mengetahui bahwa anak Anda telah memberikan informasi pribadi, silakan hubungi kami.

8. Perubahan Kebijakan Privasi

Kami dapat memperbarui Kebijakan Privasi ini dari waktu ke waktu. Perubahan akan diberitahukan melalui pembaruan aplikasi. Kami sarankan Anda meninjau halaman ini secara berkala.
